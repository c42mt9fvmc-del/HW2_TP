# HW2_TP Система рецептов и списка покупок
Проект реализует систему работы с рецептами и ингредиентами на Python.

В проекте реализованы классы:

Ingredient — описание ингредиента;
Recipe — рецепт блюда;
ShoppingList — список покупок;
DietaryRecipe — рецепт с диетической категорией.

Проект содержит тесты для проверки корректности работы программы.

Установка
Склонируйте репозиторий:
git clone https://github.com/c42mt9fvmc-del/HW2_TP.git
Затем:
cd HW2_TP

Установите зависимости:
pip install -r requirements.txt

Запуск тестов:
pytest -v

Запуск кода:
python3 recipes.py
